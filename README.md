Farmhouse Website using HTML (SEMANTICS) 

In the first task, I created a basic farmhouse website using only HTML. The focus was on building a proper page structure without styling. The website includes sections such as header, navigation menu, farmhouse details, booking form, and contact information.

Farmhouse Website using CSS & Responsiveness

In the second task, I enhanced the website by adding CSS styling. I improved the layout, colors, fonts, and overall appearance of the website. I also made the website responsive using media queries so that it works well on mobile, tablet, and desktop devices.

Responsive Product List using CSS Grid Layout

In the final task, I developed a responsive product list page using CSS Grid. The page displays products in a card layout with images, names, and prices. The grid automatically adjusts the number of columns based on screen size, ensuring a smooth and user-friendly experience across different devices.

Purchase order and invoice generation(Javascript)

This is a JavaScript-based Purchase Order and Invoice Management system that automates PO creation, invoice generation, and payment tracking. It calculates trainer payments based on payment type and duration and generates invoices only after training completion. The system assigns due dates, detects overdue invoices, and simulates email alerts for pending payments.

Finance Management System (Javascript)

This is a Financial system implemented using JavaScript OOP concepts such as inheritance, encapsulation, and polymorphism. It supports multiple account types (Savings, Checking, Investment), transaction tracking, investments, and insurance management.
